# Smart To-Do List

A responsive task management web application built with HTML, CSS, and JavaScript. Organize tasks, assign priorities and categories, set due dates, and track task completion through a simple, light-blue interface.

## Features

- Add and manage tasks
- Set priorities: Low, Medium, High
- Organize tasks by category: Study, Personal, Work, Other
- Assign due dates
- Mark tasks as completed
- Filter tasks by status: All, Active, Completed
- Edit and delete tasks
- Track remaining tasks
- Persist tasks using Local Storage
- Responsive user interface

*Note: Features are being implemented progressively during development.*

## Tech Stack

- **HTML5** — Page structure
- **CSS3** — Styling and responsive layout
- **JavaScript** — Application logic and DOM manipulation
- **Local Storage** — Persistent task data
