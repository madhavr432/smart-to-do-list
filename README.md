# Smart To-Do List

A simple, responsive task management web application built using HTML, CSS, and JavaScript. It helps users organize daily tasks by priority, category, and due date.

## Live Demo

[**View Smart To-Do List**](https://smart-to-do-list-xi.vercel.app/)

## Features

- **Add Tasks:** Create tasks with a title, priority, category, and due date.
- **Priority Management:** Assign Low, Medium, or High priority to tasks.
- **Task Categories:** Organize tasks into Study, Personal, Work, or Other categories.
- **Due-Date Tracking:** Identify tasks that are overdue, due today, or upcoming.
- **Task Status:** Mark tasks as Active or Completed.
- **Task Filtering:** View All, Active, or Completed tasks.
- **Delete Tasks:** Remove tasks when they are no longer needed.
- **Responsive Interface:** Use the application on desktop and mobile screens.

## Tech Stack

- **HTML5** — Application structure
- **CSS3** — Styling, layout, and responsive design
- **JavaScript (Vanilla JS)** — Task management and application logic
- **Vercel** — Deployment and hosting

## Getting Started

### Prerequisites

A modern web browser and a code editor, such as Visual Studio Code.

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/madhavr432/smart-to-do-list.git
   ```

2. Navigate to the project directory:

   ```bash
   cd smart-to-do-list
   ```

3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

No package installation or build process is required.

## How It Works

1. Enter a task title.
2. Select its priority and category.
3. Optionally choose a due date.
4. Click **Save Task** or press Enter.
5. Track the task's due-date status and completion state.
6. Use the filters to view all tasks, active tasks, or completed tasks.

## Current Limitations

- Tasks are stored in a JavaScript array and are not persisted across page refreshes.
- Task search and cloud synchronization are not implemented.
